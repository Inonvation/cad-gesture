# 常见问题排查 (Troubleshooting)

> 日志文件：`%TEMP%\cad-gesture.log`（Windows 临时目录，"关于"页可一键打开）。
> 反馈问题请附上日志与配置（`%APPDATA%\CADGesture\config.json`），到 [GitHub Issues](https://github.com/Inonvation/cad-gesture/issues) 提交。

## 1. 手势完全没反应

按顺序检查：

1. **确认程序在运行**：右下角托盘应有 CAD 手势图标；没有则重新启动程序。
2. **确认在 CAD 窗口内操作**：工具只在 AutoCAD / 中望CAD / 你添加的自定义应用窗口内响应。在桌面或其他软件里长按右键不弹圆盘属正常。
3. **触发键是否被占用**：罗技/雷蛇等鼠标驱动、其他手势软件可能独占右键或侧键。可在设置里把触发键临时换成中键再试。
4. **杀毒软件拦截**：钩子类工具常被杀软拦截，把 CADGesture 加入杀软白名单/信任区（火绒、360、Windows Defender 等）。
5. **其他手势软件冲突**：Quicker、WGestures 等同样安装低级鼠标钩子，同时开启时可能只有一个生效。先退出其他手势软件测试。
6. **输入法**：命令发送前程序会自动切英文输入法；首次使用请先手动切一次英文，避免命令被中文输入法吞掉。

## 2. 菜单弹出了，但划到扇区没反应

- 该扇区可能是空扇区（没绑定命令）。在配置界面点开该扇区，确认"快捷键或 CAD 命令"至少填了一项。
- 中望CAD 机械版命令需要对应 CAD 版本支持；命令名不被识别时 CAD 里也不会有动作。

## 3. 更新失败

- **下载失败**：检查网络。国内访问 GitHub 可能较慢，可稍后重试，或手动到 [Release 页](https://github.com/Inonvation/cad-gesture/releases) 下载最新版。
- **安装失败**：安装包被 SmartScreen/杀软拦截时，程序会提示失败并保留安装包路径，可手动双击安装。
- 更新不丢失配置：配置在 `%APPDATA%\CADGesture`，与安装目录无关。

## 4. SmartScreen "未知发布者"

安装包未做代码签名，Windows 可能提示"未知发布者"。点击"更多信息"→"仍要运行"即可。程序是开源工具，源码可查。

## 5. 其他问题

查看日志 `%TEMP%\cad-gesture.log`，把最后几十行连同配置、CAD 版本一起发到 Issues。
